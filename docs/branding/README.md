# FDR Sentinel identity

Selected direction: concept 3, the navy/cobalt architectural FS monogram in
`logo-concepts-2026-10-28/03-sentinel-monogram.png`.

The production transparent symbol is
`apps/web/public/brand/fdr-sentinel-monogram-v1.png`. It was prepared with the
built-in image generator from the approved reference, with this edit prompt:

> Extract only the existing FS monogram, remove lettering/background, preserve its
> silhouette, proportions, navy/cobalt arrangement, angles and negative spaces;
> use transparent alpha with a small safety margin, and no new shapes or text.

The shared `Brand` component uses the symbol beside accessible HTML brand text on
both the public entry and workspace sidebar. A light backing in dark mode preserves
the approved navy and cobalt colors. The existing SVG favicon was redrawn as a
compact geometric adaptation of the selected symbol on a light tab-safe background.
Its versioned link refreshes previously cached favicons. No other concepts were
removed, and no application or demo processing behavior changes with this identity.
